# data/onchain/

`amm_swaps_<date>.csv` is a committed snapshot of a locally simulated
trading session against `onchain/src/ConstantProductPool.sol`, generated by
`tools/amm_sim.py`.

- **Source:** not external data. `tools/amm_sim.py` starts its own local
  Anvil node (chain id 31337), deploys the pool from `onchain/out/`'s
  compiled artifacts, seeds it with 1,000,000 units of liquidity on each
  side, then drives 40 swaps through `web3.py` with alternating direction
  and randomized size, seeded (`RANDOM_SEED = 20260903`) so the output is
  reproducible byte-for-byte on every run.
- **Real chain execution, not a spreadsheet model.** Every row's
  `amount_out` and reserve columns come from an actual EVM transaction
  receipt on a real (if local and disposable) Anvil node, not a Python
  reimplementation of the constant-product formula. `qrp-onchain`'s LP
  P&L/impermanent-loss/fee-capture analysis (see `docs/spec-onchain.md`)
  reads this file as its only input.
- **What this is not:** no real capital, no public testnet or mainnet
  deployment, no real trader or market-making counterparty. The trade
  sequence is a synthetic random walk, not historical or live market data.
- **Refreshing it:**
  ```bash
  python3 tools/amm_sim.py > data/onchain/amm_swaps_$(date +%Y-%m-%d).csv
  ```
  Needs `web3` (`pip install web3`) and Foundry's `forge`/`anvil` on PATH.
  Not run by CI or by any Java code -- a clean clone of `qrp-onchain`'s
  tests reads only the committed CSV, so the build stays fully offline and
  reproducible, same convention `data/energy/README.md` follows.
