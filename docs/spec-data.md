# Spec — `qrp-data`

Status: implemented (step 2)

## Why this module exists

A research platform is unusable without data, and a *public* research platform
is unusable if its data needs an account. This module gives the platform one
provider that works from a clean clone with no credentials, no network and no
vendor licence, and defines the shape a real provider has to fit.

## Requirements

| # | Requirement |
| --- | --- |
| R1 | Load bars from a directory of CSV files, offline |
| R2 | Fail on unusable data, naming the file and the line |
| R3 | Serve a half-open time range `[from, to)` |
| R4 | Enumerate what it can serve, without parsing every series |
| R5 | Ship a sample data set that a clone can run immediately |
| R6 | Leave a documented seam for a live provider that cannot ship here |

## Layout

```
data/sample/instruments.csv    symbol,currency,asset_class,timeframe,file
data/sample/SYNA_1d.csv        timestamp,open,high,low,close,volume
```

## Design decisions

**D1 — A manifest, not a naming convention.** A price file cannot say what it
is: currency and asset class are not in the rows. Encoding them in the file name
means a parser guesses, and a guess is how a USD series ends up priced in euros.
The manifest also makes `available()` a single small read instead of a parse of
every series in the directory.

**D2 — Series are keyed by symbol and timeframe, and a mismatch is an error.**
`load` takes a full `Instrument`. If the manifest declares `SYNETF` as an ETF and
the caller asks for it as an equity, the provider says so rather than returning
bars labelled with an instrument the caller invented. Silent acceptance would put
a wrong `Instrument` inside the returned series, where it would resurface much
later as a currency bug.

**D3 — Every parse error names file and line.** `TEST_1d.csv:3 open must be
positive, got: 0.0`. The first question anyone asks about a rejected data set is
*which row*, and a stack trace without that answer costs a bisect.

**D4 — The manifest is read eagerly, the series lazily.** A directory that
references a missing file fails when the provider is built, not on the first
backtest that happens to touch that series. Bars are parsed per `load` call
because a full data set does not need to live in memory to answer one range.

**D5 — Validation is delegated, not duplicated.** Bar invariants belong to
`Bar`, ordering belongs to `BarSeries`; the loader catches what they throw and
re-reports it with the file position. One definition of a valid bar, enforced in
one place, regardless of which provider produced it.

**D6 — The sample data is synthetic and says so.** Seeded geometric Brownian
motion, symbols `SYNA`, `SYNB`, `SYNETF`, generated by
`SyntheticSeriesGenerator` and committed. Redistributing vendor history raises a
licensing question this repository does not need to answer, a generated series is
reproducible where a downloaded one is not, and a reviewer who sees `SYNA` cannot
mistake a demo for a backtest on real prices. Regenerate with
`mvn -pl qrp-data exec:java`: same seeds, same bytes.

**D7 — Rounding happens before the invariants are re-imposed.** Prices are
rounded to cents to look like real quotes, which can push a rounded high below a
rounded close. The generator re-applies `high = max(high, open, close)` after
rounding, so the emitted bars are ones `Bar` will accept.

## The live provider seam

A broker-backed provider — the one this platform was originally written against —
implements `MarketDataProvider` outside this repository. It needs credentials, a
running gateway and a market data subscription, none of which a reviewer cloning
the project has, and its request pacing rules are not something a public demo
should encourage anyone to test against. The interface is the contract; the CSV
provider is the reference implementation of it.

## Out of scope

Corporate action adjustment, survivorship-bias-free universes, tick data,
order books, and any live subscription. A backtest on unadjusted prices across a
split is wrong, so a real data set for this platform must arrive already
adjusted; the platform does not pretend to do it.
